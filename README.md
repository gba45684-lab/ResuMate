# ResuMate

Production structure for the ResuMate resume builder.

## Project layout

- `www/index.html` — production web app entry point
- `scripts/` — validation/build helpers
- `capacitor.config.ts` — Capacitor configuration
- `android/` — generated by the Android build workflow
- `.github/workflows/` — CI/build automation

## Local build

```bash
npm ci
npm run check
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

The approved ResuMate interface remains the source of truth; restructuring does not redesign the UI.
